# Public artifacts and private scientific originals

The 13 September cleanup changes publication copies only. The frozen protocol at
`98b5e09199a5eef0c46be452793e953f5a2af31e`, eligibility rules, feasibility-failure
label, funnel counts, model samples and biological results are unchanged.

## Scope and policy

The [audit](../results/publication_safety/audit.md) covers all 260 files in the
initial index, including every tracked or staged file under `docs/` and `results/`.
Differing index and working-copy bytes were audited separately. Each paper-prose
field, copied table string and encoded source request in the affected artifacts
has a private reference in its public copy. Short reconstruction fragments and
UTF-8 hex excerpts are also removed. No public table transcription remains in
the audited artifacts. Tables of the project's derived counts remain available.

Nine attributed plant-name quotations in `config/pilot_name_mappings.json` remain;
the longest has 13 whitespace-delimited words. Each has a source ID and block ID.
The source has an explicit CC BY 4.0 licence, recorded in the
[licence inventory](../results/publication_safety/licences.json). Bibliographic
titles and author lists are metadata. Invented synthetic tests are labelled and
are separate from retrieved-paper prose. Fifteen words is the user's publication
limit; it is not a legal determination that a particular quotation is permitted.

The inventory records 631 represented sources, including 517 LOTUS bibliography-only
DOI references whose article-text licences remain unassessed. It records clear reuse
terms for 78 sources, uncertainty for 551, and no recorded permission under the
located terms for two. Non-commercial restrictions and missing licences stay visible. Saverschek
2010, published in Animal Behaviour by Elsevier, has an all-rights-reserved notice
and no recorded redistribution permission. Full text remains private regardless
of the licence classification.

## Exact originals and offsets

Full text is retained locally and is not redistributed. The ignored directories
`data/raw/` and `data/interim/` retain the original caches and source blocks.
`data/interim/publication_safety/originals/` preserves all 260 pre-cleanup working
files at their repository-relative paths. `index_originals/` separately preserves
their staged bytes. `snapshot.json` records both sets of hashes. Existing private
source files were read without modification.

Each affected JSON file has a `publication` notice and a redaction ledger. A
removed value points to a ledger record with its private path, original file
SHA-256, structural JSON path, UTF-8 byte start and exclusive end, and span hash.
JSON offsets include the encoded value's quotation marks and escapes; the decoded
value has a separate UTF-8 hash. Matched source spans also identify the original
block, its hash, and offsets in the decoded block's UTF-8 bytes. Rejected model
quotations can lack an exact source span; their private proposal remains resolvable.
The audit JSON holds the Markdown quotation's private span reference.

Historical request, score and preservation hashes continue to identify original
private bytes. Public projection hashes are listed separately. No original hash
was replaced to make an integrity check pass.

## Local verification and replay

Run from the prepared local checkout:

```bash
.venv/bin/python -m scripts.publication_safety verify
.venv/bin/python -m scripts.publication_safety replay
.venv/bin/python -m scripts.publication_safety test
```

The replay command creates an isolated temporary mirror, copies the original
reference artifacts, uses the saved frozen extraction dispatchers, and reads the
existing private caches offline. It writes every replay output into the temporary
directory. It compares nine baseline artifacts and thirteen artifacts for each
of v6 samples 1–4, with the unchanged baseline scoring convention. No model or
source requests occur. Frozen source inputs and all private originals are checked
before and after replay. The temporary mirror is removed when the check finishes.

The public snapshot alone cannot reconstruct the paper or replay its extraction.
An authorized local checkout needs the existing private inputs and snapshot.
The test command runs the complete suite in the private mirror because integration
tests require original reference hashes and evidence strings. Those checks remain
unchanged. Public-projection tests also run there against invented fixtures.
Reports regenerated by scientific scripts can include paper quotations and must
pass publication checks before staging.

## Release boundary

This cleanup covers the current index and working files. Earlier Git commits
contain unsanitized reference artifacts; their blobs remain in history. No history
rewrite, commit or push is part of this task. Publishing that history requires a
separate approved cleanup. Existing untracked or unstaged implementation work also
needs a release inventory. No files were moved out of tracking in this cleanup.
